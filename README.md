# Personal Portfolio Website

## Overview

This is a responsive Personal Portfolio Website developed using HTML and CSS. The website showcases my profile, skills, projects, resume, and contact information in a clean and modern design.

This project was developed as part of the Synent Technologies Web Development Internship Program.

## Features

* Responsive single-page portfolio website
* Professional header section
* About Me section
* Skills section
* Projects showcase
* Resume download option
* Contact information with LinkedIn and GitHub links
* Modern UI with gradient effects and hover animations

## Technologies Used

* HTML5
* CSS3
* Google Fonts (Poppins)
